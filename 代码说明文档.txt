========================================================
二、代码架构说明（四层结构）
========================================================

本项目采用经典的 Spring Boot 四层架构：

  请求流程：浏览器 → Controller → Service → Repository → 数据库

  1. Controller（控制器层）
     - 接收浏览器的请求（URL），调用 Service 处理业务
     - 将处理结果传给前端页面（Model）或重定向
     - 文件位置：controller/ 目录下

  2. Service（业务逻辑层）
     - 处理具体的业务逻辑（增删改查的组合操作）
     - 调用 Repository 与数据库交互
     - 文件位置：service/ 目录下

  3. Repository（数据访问层）
     - 直接与数据库交互，执行 SQL 操作
     - 使用 Spring Data JPA，大部分方法自动生成
     - 文件位置：repository/ 目录下

  4. Entity（实体层）
     - 定义数据库表对应的 Java 对象
     - 每个实体类对应数据库中的一张表
     - 文件位置：entity/ 目录下

========================================================
四、角色与权限说明
========================================================

系统有两种角色：

  ┌──────────────┬───────────────────────────────────┐
  │ 角色          │ 权限                              │
  ├──────────────┼───────────────────────────────────┤
  │ 普通用户      │ 浏览所有内容                      │
  │ （role=0）    │ 加入社团                          │
  │              │ 发表留言                          │
  │              │ 查看个人中心、修改个人信息         │
  │              │ 查看"我的社团"                    │
  ├──────────────┼───────────────────────────────────┤
  │ 系统管理员    │ 拥有普通用户的所有权限            │
  │ （role=2）    │ 管理用户（查看、删除）            │
  │              │ 管理社团（创建、编辑、删除）       │
  │              │ 管理活动（发布、编辑、删除）       │
  │              │ 管理资讯（发布、编辑、删除）       │
  │              │ 管理公告（发布、编辑、删除）       │
  │              │ 管理留言（回复、删除）             │
  │              │ 管理成员（审批、移除、改职位）     │
  └──────────────┴───────────────────────────────────┘

  权限控制位置：
  - 后端：各 Controller 中通过 session 获取当前用户，
          判断 loginUser.getRole() == 2 来控制管理操作
  - 前端：各 HTML 模板中通过 Thymeleaf 的 th:if 判断
          session.loginUser.role == 2 来控制按钮显示

五、各文件详细说明
========================================================

【配置文件】
------------------------------------------

1. pom.xml
   作用：Maven 项目配置，定义了项目依赖的第三方库
   修改场景：需要引入新的功能库时修改
   当前依赖：
   - spring-boot-starter-web      Web框架
   - spring-boot-starter-thymeleaf 前端模板引擎
   - spring-boot-starter-data-jpa  数据库操作
   - mysql-connector-java          MySQL驱动
   - lombok                        简化代码（自动生成getter/setter）
   - thymeleaf-layout-dialect      模板布局

2. src/main/resources/application.yml
   作用：项目核心配置文件
   常见修改：
   - 修改端口号：     server.port（默认8080）
   - 修改数据库地址： spring.datasource.url
   - 修改数据库用户名：spring.datasource.username
   - 修改数据库密码： spring.datasource.password

3. src/main/resources/data.sql
   作用：项目启动时自动执行的初始化数据脚本
   说明：每次启动都会执行，但使用了 NOT EXISTS 判断，
         已存在的数据不会重复插入
   修改场景：
   - 想修改预置的社团信息 → 修改 INSERT INTO t_club 部分
   - 想修改预置的活动信息 → 修改 INSERT INTO t_activity 部分
   - 想修改预置的资讯信息 → 修改 INSERT INTO t_news 部分
   - 想修改预置的公告信息 → 修改 INSERT INTO t_notice 部分
   - 想增减测试用户     → 修改 INSERT INTO t_user 部分
   ★ 修改后需要先清空数据库再重启才能生效（参见部署文档"问题7"）

   - 修改注册逻辑（如加字段）  → 修改 doRegister 方法
   - 修改管理员登录后跳转页面  → 修改 doLogin 中的 redirect 地址

9. controller/ClubController.java
   作用：处理社团相关请求
   功能：社团列表、详情、创建、编辑、删除、加入社团

10. controller/ActivityController.java
    作用：处理活动相关请求
    功能：活动列表、详情、发布、编辑、删除

11. controller/NewsController.java
    作用：处理资讯相关请求
    功能：资讯列表、详情、发布、编辑、删除

12. controller/NoticeController.java
    作用：处理公告相关请求
    功能：公告列表、详情、发布、编辑、删除

13. controller/MessageController.java
    作用：处理留言相关请求
    功能：留言列表、发表留言、管理员回复、删除留言

14. controller/MemberController.java
    作用：处理社团成员相关请求
    功能：成员列表、审批加入、拒绝、移除、修改职位、我的社团

15-21. entity/ 目录下的 7 个实体类
    作用：定义数据库表结构（一个类对应一张表）
    说明：使用 @Entity 注解，JPA 会自动根据类的字段创建数据库表
    修改场景：
    - 想给某张表增加新字段 → 在对应的实体类中添加新的 private 字段
      例如想给社团表加一个"创建年份"字段：
      在 Club.java 中加一行：private Integer foundYear;
      然后重启程序，JPA 会自动在表中添加对应的列
    ★ 注意：只能增加字段，不要删除已有字段，否则可能导致数据丢失

22-28. repository/ 目录下的 7 个接口
    作用：定义数据库操作方法
    说明：继承 JpaRepository，常用的增删改查方法自动生成
    修改场景：
    - 想增加新的查询方式 → 在对应接口中添加方法
      例如想按分类查询社团：
      在 ClubRepository.java 中加一行：
      List<Club> findByCategory(String category);
      Spring Data JPA 会根据方法名自动生成 SQL

29-35. service/ 目录下的 7 个服务类
    作用：封装业务逻辑，调用 Repository 操作数据库
    修改场景：
    - 想修改某个业务的处理逻辑 → 修改对应 Service 中的方法

【需求1】修改网站名称
------------------------------------------
文件：templates/fragments/header.html
操作：搜索"校园社团网站"，将其替换为您想要的名称
     （该文件中出现 2 处，导航栏和页脚各一处，都要改）
影响：所有页面的顶部导航和底部页脚都会同步更新


【需求2】修改网站主题颜色
------------------------------------------
文件：static/css/style.css
操作：搜索以下颜色值并替换：
     #2e7d32  →  主色调深绿（导航栏、按钮、标题等）
     #43a047  →  主色调浅绿（悬停效果、强调色等）
     #e8f5e9  →  极浅绿背景色
     #f0f7f0  →  浅绿悬停背景色

     例如想改成蓝色主题：
     #2e7d32 → #1565c0（深蓝）
     #43a047 → #1976d2（浅蓝）
     #e8f5e9 → #e3f2fd（极浅蓝）
     #f0f7f0 → #e8f0fe（浅蓝悬停）

     用记事本的"替换"功能（Ctrl+H）批量替换即可


【需求3】修改管理员密码
------------------------------------------
方式一：修改初始数据（重置后生效）
  文件：data.sql
  操作：找到 admin 的 INSERT 语句，修改 'admin123' 为新密码
  注意：需要先清空数据库再重启

方式二：直接改数据库（立即生效）
  打开命令提示符，执行：
  mysql -u root -proot -e "UPDATE t_user SET password='新密码' WHERE username='admin';" campus_community


【需求4】添加新的管理员账号
------------------------------------------
方式一：修改初始数据
  文件：data.sql
  操作：复制 admin 的 INSERT 语句，修改用户名和密码
  注意：role 必须设为 2

方式二：直接在数据库中添加
  mysql -u root -proot -e "INSERT INTO t_user(username,password,real_name,role,create_time) VALUES('新用户名','密码','姓名',2,NOW());" campus_community


【需求5】修改预置的示例数据（社团、活动、资讯等）

八、Thymeleaf 模板语法速查
========================================================

前端页面使用 Thymeleaf 模板引擎，以下是常用语法：

  显示文字：   th:text="${变量名}"
  判断显示：   th:if="${条件}"
  循环列表：   th:each="item : ${列表}"
  链接地址：   th:href="@{/路径}"
  表单提交：   th:action="@{/提交路径}"
  引入片段：   th:replace="fragments/header :: navbar"

  示例：
  <span th:text="${user.username}">用户名</span>
  → 显示用户的用户名

  <a th:if="${session.loginUser.role == 2}">管理</a>
  → 只有管理员才能看到这个链接

  <div th:each="club : ${clubs}">
      <h3 th:text="${club.name}">社团名</h3>
  </div>
  → 循环显示所有社团

九、注意事项
========================================================

  1. 修改 Java 代码后必须重启项目才能生效
  2. 修改 HTML/CSS 文件后，刷新浏览器即可看到效果
     （如果没有效果，尝试 Ctrl+F5 强制刷新）

  4. 建议修改前先备份原文件
  5. 不要删除实体类（entity/）中已有的字段，只能增加
  6. 图标名称可在 https://icons.getbootstrap.com/ 查找
  7. Bootstrap Icons 是在线加载的，需要联网才能显示图标
