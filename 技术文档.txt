========================================================
    校园社团网站 — 技术文档
========================================================


========================================================
一、技术架构总览
========================================================

本项目采用 Spring Boot + Thymeleaf + MySQL 的经典
B/S（浏览器/服务器）架构，是一个前后端不分离的
Java Web 应用程序。

整体架构如下：

  ┌──────────────────────────────────────────────────────┐
  │                  浏览器（Chrome/Edge）                │
  │          HTML + CSS + Bootstrap Icons                 │
  └──────────────┬──────────────────────┬────────────────┘
                 │  HTTP 请求           │  HTML 页面响应
  ┌──────────────▼──────────────────────▼────────────────┐
  │              Spring Boot 内嵌 Tomcat                  │
  │  ┌────────────────────────────────────────────────┐  │
  │  │  Controller 层（接收请求、返回视图）            │  │
  │  ├────────────────────────────────────────────────┤  │
  │  │  Service 层（业务逻辑处理）                     │  │
  │  ├────────────────────────────────────────────────┤  │
  │  │  Repository 层（数据库访问 / Spring Data JPA）  │  │
  │  ├────────────────────────────────────────────────┤  │
  │  │  Entity 层（实体类 / 数据模型）                 │  │
  │  └────────────────────────────────────────────────┘  │
  │           Thymeleaf 模板引擎 渲染页面                 │
  └──────────────┬───────────────────────────────────────┘
                 │  JDBC 连接
  ┌──────────────▼───────────────────────────────────────┐
  │              MySQL 8.0 数据库                         │
  │         数据库名：campus_community                    │
  │         字符集：utf8mb4                               │
  └──────────────────────────────────────────────────────┘


========================================================
二、前端技术
========================================================

1. 模板引擎：Thymeleaf
   ─────────────────────────────────────────────────────
   版本：随 Spring Boot 2.7.18 自带（Thymeleaf 3.x）
   说明：Thymeleaf 是一种服务端 Java 模板引擎，能够
         处理 HTML、XML、JavaScript、CSS 等。本项目
         使用 Thymeleaf 在服务端渲染页面，将后端数据
         动态填充到 HTML 模板中，再返回给浏览器展示。
   配置：
     - 模板路径：classpath:/templates/
     - 文件后缀：.html
     - 编码格式：UTF-8
     - 开发模式已关闭缓存（thymeleaf.cache: false）
   扩展：使用了 thymeleaf-layout-dialect 布局方言，
         支持页面片段复用（如公共导航栏、页脚等）。

2. 页面结构：HTML5
   ─────────────────────────────────────────────────────
   采用标准 HTML5 编写，使用 Thymeleaf 的 th:* 属性
   进行数据绑定和条件渲染。
   模板文件位于 src/main/resources/templates/ 目录下，
   共包含以下模块页面：
     - index.html           首页
     - login.html           登录页
     - register.html        注册页
     - fragments/header.html 公共导航栏与页脚片段
     - club/                社团相关页面（列表/详情/新增/编辑）
     - activity/            活动相关页面
     - news/                资讯相关页面
     - notice/              公告相关页面
     - message/             留言板页面
     - member/              成员管理与我的社团页面
     - admin/               管理员专用页面（用户管理）
     - user/                个人中心页面

3. CSS 样式：自定义样式表
   ─────────────────────────────────────────────────────
   文件：src/main/resources/static/css/style.css
   说明：全站唯一的 CSS 样式文件，约 650+ 行，采用
         纯手写 CSS 实现响应式布局，不依赖 Bootstrap
         等 CSS 框架。
   特点：
     - 使用 CSS Flexbox 和 Grid 布局
     - 使用 CSS 变量管理主题色（绿色主题）
     - 支持响应式设计
     - 统一的卡片、按钮、表单、表格样式

4. 图标库：Bootstrap Icons
   ─────────────────────────────────────────────────────
   版本：1.11.3
   加载方式：CDN 在线加载
   CDN地址：https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css
   说明：仅使用了 Bootstrap 的图标字体库，未使用
         Bootstrap 的 CSS 框架和 JS 组件。
         图标通过 <i class="bi bi-xxx"></i> 标签引用。

5. 字体方案
   ─────────────────────────────────────────────────────
   使用系统字体栈：'Microsoft YaHei', 'PingFang SC',
                   -apple-system, sans-serif
   优先使用微软雅黑（Windows）和苹方（macOS），
   无需额外加载网络字体，提升页面加载速度。

6. 前端交互
   ─────────────────────────────────────────────────────
   本项目未使用 JavaScript 框架（如 Vue、React 等），
   页面交互主要通过以下方式实现：
     - 表单提交：传统的 HTML form 表单同步提交
     - 页面跳转：服务端重定向（redirect）
     - 条件显示：Thymeleaf 的 th:if 条件渲染
     - 数据循环：Thymeleaf 的 th:each 列表渲染


========================================================
三、后端技术
========================================================

1. 核心框架：Spring Boot
   ─────────────────────────────────────────────────────
   版本：2.7.18（Spring Boot 2.x 系列最终版本）
   说明：Spring Boot 是基于 Spring 框架的快速开发脚手架，
         内置了 Tomcat 服务器，可以打包成独立的可运行
         JAR 文件，无需额外部署 Web 服务器。
   核心特性：
     - 自动配置（Auto-Configuration）
     - 内嵌 Tomcat 服务器
     - Starter 依赖管理
     - 配置文件统一管理（application.yml）

2. Web 模块：Spring MVC（spring-boot-starter-web）
   ─────────────────────────────────────────────────────
   说明：基于 Spring MVC 的 Web 开发模块，提供了
         RESTful 请求处理、请求映射、参数绑定等功能。
   使用方式：
     - @Controller 注解标识控制器类
     - @GetMapping / @PostMapping 映射请求路径
     - Model 对象传递数据到前端视图
     - HttpSession 管理用户登录状态
     - RedirectAttributes 实现重定向消息传递
   运行端口：8080（可在 application.yml 中修改）
   文件上传：支持最大 10MB 的文件上传

3. ORM 框架：Spring Data JPA + Hibernate
   ─────────────────────────────────────────────────────
   版本：随 Spring Boot 2.7.18 自带
         （Hibernate 5.x / JPA 2.2）
   说明：Spring Data JPA 是 Spring 对 JPA 规范的封装，
         底层使用 Hibernate 作为 ORM 实现。它提供了
         强大的 Repository 接口，可以根据方法名自动
         生成 SQL 查询语句。
   配置：
     - DDL 策略：hibernate.ddl-auto = update
       （自动根据实体类更新数据库表结构）
     - SQL 方言：MySQL5InnoDBDialect
     - SQL 日志：关闭（show-sql: false）
     - 延迟数据源初始化：开启
       （保证 data.sql 在表创建之后执行）
   使用方式：
     - 实体类使用 @Entity、@Table、@Id 等 JPA 注解
     - Repository 继承 JpaRepository<实体类, 主键类型>
     - 按方法名命名规则自动生成查询
       （如 findByUsername、findByClubId 等）
     - 支持 @Query 自定义 JPQL/SQL 查询

4. 代码简化工具：Lombok
   ─────────────────────────────────────────────────────
   说明：Lombok 通过注解在编译期自动生成常用的样板代码，
         减少手动编写 getter/setter/toString 等方法。
   使用注解：
     - @Data：自动生成 getter、setter、toString、
              equals、hashCode 方法

5. 登录拦截器：自定义 HandlerInterceptor
   ─────────────────────────────────────────────────────
   实现类：LoginInterceptor.java
   配置类：WebConfig.java（实现 WebMvcConfigurer）
   说明：通过自定义拦截器实现登录状态检查。
         未登录用户访问受保护页面时，自动重定向到登录页。
   免登录页面包括：首页、登录、注册、社团/活动/资讯/
                   公告的列表和详情页、留言列表页、
                   静态资源等。

6. 后端代码分层架构
   ─────────────────────────────────────────────────────
   采用经典的 Spring Boot 四层架构：

   ┌─────────────────────────────────────────────────┐
   │  Controller（控制器层）                          │
   │  接收 HTTP 请求，调用 Service，返回视图          │
   │  共 8 个控制器：                                 │
   │    IndexController    - 首页                     │
   │    UserController     - 用户/登录/注册           │
   │    ClubController     - 社团管理                 │
   │    ActivityController - 活动管理                 │
   │    NewsController     - 资讯管理                 │
   │    NoticeController   - 公告管理                 │
   │    MessageController  - 留言管理                 │
   │    MemberController   - 成员管理                 │
   ├─────────────────────────────────────────────────┤
   │  Service（业务逻辑层）                           │
   │  封装业务逻辑，调用 Repository 操作数据库        │
   │  共 7 个服务类                                   │
   ├─────────────────────────────────────────────────┤
   │  Repository（数据访问层）                        │
   │  继承 JpaRepository，自动生成 CRUD 操作          │
   │  共 7 个接口                                     │
   ├─────────────────────────────────────────────────┤
   │  Entity（实体层）                                │
   │  JPA 实体类，对应数据库表                        │
   │  共 7 个实体类：User, Club, Activity, News,      │
   │  Notice, Message, Member                         │
   └─────────────────────────────────────────────────┘


========================================================
四、数据库技术
========================================================

1. 数据库：MySQL
   ─────────────────────────────────────────────────────
   版本：MySQL 8.0
   驱动：mysql-connector-java 8.0.33
   数据库名：campus_community
   字符集：utf8mb4（支持中文和 Emoji）
   排序规则：utf8mb4_unicode_ci
   连接地址：jdbc:mysql://localhost:3306/campus_community
   连接参数：
     - useUnicode=true         使用 Unicode 编码
     - characterEncoding=utf-8 字符编码 UTF-8
     - useSSL=false            不使用 SSL 连接
     - serverTimezone=Asia/Shanghai  时区设为上海
     - allowPublicKeyRetrieval=true  允许公钥检索
   默认账号：root / root

2. 数据库表设计
   ─────────────────────────────────────────────────────
   系统共 7 张数据表，由 JPA 根据实体类自动创建：

   ┌──────────────┬──────────────────────────────────┐
   │ 表名          │ 说明                             │
   ├──────────────┼──────────────────────────────────┤
   │ t_user        │ 用户表（含普通用户和管理员）     │
   │ t_club        │ 社团表                           │
   │ t_activity    │ 活动表                           │
   │ t_news        │ 资讯表                           │
   │ t_notice      │ 公告表                           │
   │ t_message     │ 留言表                           │
   │ t_member      │ 社团成员关联表                   │
   └──────────────┴──────────────────────────────────┘

   表创建方式：Hibernate 自动建表（ddl-auto: update）
   初始数据：通过 data.sql 脚本在启动时自动插入
   数据初始化模式：spring.sql.init.mode = always

3. 存储引擎
   ─────────────────────────────────────────────────────
   使用 InnoDB 存储引擎（MySQL 8.0 默认引擎），
   配置方言为 MySQL5InnoDBDialect。
   InnoDB 支持事务、行级锁和外键约束。

十、项目配置文件说明（application.yml）
========================================================

  server:
    port: 8080                    # 服务端口

  spring:
    datasource:                   # 数据源配置
      url: jdbc:mysql://localhost:3306/campus_community
      username: root              # 数据库用户名
      password: root              # 数据库密码
      driver-class-name: com.mysql.cj.jdbc.Driver

    jpa:                          # JPA/Hibernate 配置
      hibernate:
        ddl-auto: update          # 自动更新表结构
      show-sql: false             # 不打印 SQL 日志
      properties:
        hibernate:
          format_sql: true        # 格式化 SQL
          dialect: MySQL5InnoDBDialect  # MySQL 方言
      defer-datasource-initialization: true

    sql:
      init:
        mode: always              # 每次启动执行 data.sql
        encoding: UTF-8

    thymeleaf:                    # Thymeleaf 配置
      cache: false                # 关闭缓存（开发模式）
      prefix: classpath:/templates/
      suffix: .html
      encoding: UTF-8

    servlet:
      multipart:                  # 文件上传配置
        max-file-size: 10MB
        max-request-size: 10MB


========================================================
十一、技术选型理由
========================================================

  1. Spring Boot 2.7.18
     - Java 生态中最流行的 Web 开发框架
     - 约定优于配置，开箱即用
     - 2.7.x 是 Spring Boot 2 系列的最终维护版本，
       稳定性高，社区资源丰富

  2. Thymeleaf（前后端不分离）
     - 适合传统 Web 应用和毕业设计项目
     - 模板语法简洁，学习成本低
     - 无需额外搭建前端工程，降低项目复杂度

  3. Spring Data JPA + Hibernate
     - 自动建表，无需手动编写 DDL
     - 方法名派生查询，大幅减少 SQL 编写
     - 适合中小型项目的快速开发

  4. MySQL 8.0
     - 全球最流行的开源关系型数据库
     - 性能优秀，社区活跃
     - 对中文支持良好（utf8mb4）

  5. Maven

  6. Bootstrap Icons（仅图标）
